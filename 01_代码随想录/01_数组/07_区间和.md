# [07_区间和（第九期模拟笔试）](https://kamacoder.com/problempage.php?pid=1070)

给定一个整数数组 `Array`，请计算该数组在每个指定区间内元素的总和。

第一行输入为整数数组 `Array` 的长度 `n`，接下来 `n` 行，每行一个整数，表示数组的元素。随后的输入为需要计算总和的区间下标：`a，b （b > = a）`，直至文件结束。

输出每个指定区间内元素的总和。

###### 输入示例

```
5
1
2
3
4
5
0 1
1 3
```

###### 输出示例

```
3
9
```

###### 提示信息

数据范围：
`0 < n <= 100000`

## 题解

### 暴力解

给一个区间，把这个区间的和都累加一遍。

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt(); // 读取数组的大小
        int[] arr = new int[n]; // 创建一个整型数组
        for (int i = 0; i < n; i++) {
            arr[i] = scanner.nextInt(); // 读取数组元素
        }
        while (scanner.hasNextInt()) { // 检查是否还有更多的输入
            int a = scanner.nextInt(); // 读取区间的起始索引
            int b = scanner.nextInt(); // 读取区间的结束索引
            int sum = 0; // 初始化区间和
            for (int i = a; i <= b && i < n; i++) { // 遍历区间并累加
                sum += arr[i];
            }
            System.out.println(sum); // 输出区间和
        }
        scanner.close(); // 关闭扫描器
    }
}
```

- 时间复杂度：$O(n * m) m$

### 前缀和

前缀和的思想是重复利用计算过的子数组之和，从而降低区间查询需要累加计算的次数。

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        int n = scanner.nextInt();
        int[] vec = new int[n];
        int[] p = new int[n];

        int presum = 0;
        for (int i = 0; i < n; i++) {
            vec[i] = scanner.nextInt();
            presum += vec[i];
            p[i] = presum;
        }

        while (scanner.hasNextInt()) {
            int a = scanner.nextInt();
            int b = scanner.nextInt();

            int sum;
            if (a == 0) {
                sum = p[b];
            } else {
                sum = p[b] - p[a - 1];
            }
            System.out.println(sum);
        }

        scanner.close();
    }
}
```

时间复杂度：$O(1)$
